## Spacing Scale

#### 1 rem = 16px

| Name      | Giá trị | Dùng cho                            |
| --------- | ------- | ----------------------------------- |
| `space-1` | 4px     | Khoảng cách nhỏ nhất (icon & label) |
| `space-2` | 8px     | Trong component                     |
| `space-3` | 12px    | Padding nhỏ                         |
| `space-4` | 16px    | Margin mép màn hình, padding card   |
| `space-6` | 24px    | Giữa các section                    |
| `space-8` | 32px    | Giữa các section lớn                |

***

## Grid & Margin

* Số cột: 4 cột trên mobile.
* Lề mép (margin): 12px.
* Máng (gutter) giữa cột: 12px.

## Iconography

#### [Link bộ icon](https://www.figma.com/design/SUiVqqsdAcbPBAyEL1rqOz/Icon-Design-System)

#### Nguyên tắc

* Thống nhất **một phong cách** trên toàn sản phẩm (line _hoặc_ filled — không trộn tùy tiện).
* Cùng grid dựng và độ dày nét (stroke).
* Icon **luôn kèm nhãn** hoặc `aria-label` để hỗ trợ accessibility — không truyền tải trạng thái chỉ bằng icon.

| Name      | Giá trị | Dùng cho               |
| --------- | ------- | ---------------------- |
| `icon-sm` | 16px    | Inline cùng text       |
| `icon-md` | 20px    | Mặc định               |
| `icon-lg` | 24px    | Bottom nav, điều hướng |
| `icon-xl` | 32px    | Điểm nhấn, empty state |
