# 1. Phần cứng

_Ẩn dụ: đây là "vật liệu xây dựng" — thiết bị phần cứng cần cho hệ thống vận hành._

## Danh sách thiết bị

| Thiết bị                   | Mục đích                       | Số lượng | Trạng thái |
| -------------------------- | ------------------------------ | -------- | ---------- |
| QR Code (theo bàn/khu vực) | Điểm khởi đầu phiên order      |          |            |
| Máy POS                    | Nhận order, thanh toán         |          |            |
| Máy in bill                | In hóa đơn                     |          |            |
| Máy in bếp / bar           | In phiếu chế biến              |          |            |
| Tablet (nếu có)            | Order tại bàn hỗ trợ nhân viên |          |            |
| Màn hình bếp (nếu có)      | Hiển thị order thời gian thực  |          |            |

## Ghi chú

* Xác nhận số lượng và vị trí lắp đặt QR theo từng bàn/khu vực.
* Xác nhận model máy POS/máy in đang sử dụng để đảm bảo tương thích kết nối.
