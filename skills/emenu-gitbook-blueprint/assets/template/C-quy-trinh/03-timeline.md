# 3. Timeline

## Timeline ước lượng theo mô hình/gói

| Gói / Mô hình        | Phù hợp với                                  | Timeline  |
| -------------------- | -------------------------------------------- | --------- |
| Tiêu chuẩn           | Menu QR cơ bản                               | 2–4 tuần  |
| Chỉnh sửa            | Chỉnh sửa thêm theo bản chuẩn                | 4–6 tuần  |
| Chỉnh sửa chuyên sâu | Chỉnh sửa riêng biệt theo yêu cầu khách hàng | 6–10 tuần |

> Ghi chú: Timeline sẽ được xác nhận lại sau khi chốt workflow, scope, dữ liệu và hạ tầng.
