# 3. Phạm vi dự án

## Trong phạm vi

| Hạng mục                   | Ghi chú |
| -------------------------- | ------- |
| Thiết kế giao diện E-Menu  |         |
| Lập trình E-Menu           |         |
| Kết nối QR code thanh toán |         |
| Hệ thống báo cáo           |         |

## Ngoài phạm vi

* Quản lý kho
* CRM nâng cao
* Loyalty (nếu chưa chọn ở phần Tính năng)
* App native (nếu chỉ triển khai web qua QR)
* Thay đổi quy trình vận hành ngoài E-Menu

## Có thể mở rộng — Phase 2

* Loyalty / Tip
* Thanh toán online
* Đa ngôn ngữ
* Đặt món từ xa
* Đa chi nhánh
* Zalo OA / CRM

> Ghi chú: các hạng mục Phase 2 được quản lý tại phần "Các thay đổi → Yêu cầu mở rộng".
