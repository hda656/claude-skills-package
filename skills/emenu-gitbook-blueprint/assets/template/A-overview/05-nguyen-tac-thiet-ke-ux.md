# 5. Nguyên tắc thiết kế & UX

## Nguyên tắc thiết kế (Design Principles)

| Nguyên tắc                  | Diễn giải                                                  |
| --------------------------- | ---------------------------------------------------------- |
| Hiện đại - Rõ ràng          | Ưu tiên thông tin quan trọng (tên món, giá, hình ảnh)      |
| Nhất quán                   | Đồng bộ màu sắc, typography, theo đúng bản sắc thương hiệu |
| Tối giản thao tác           | Tối ưu các bước hoàn tất một hành động                     |
| Thân thiện thiết bị di động | Ưu tiên trải nghiệm trên màn hình nhỏ                      |

## Nguyên tắc trải nghiệm người dùng (UX Principles)

| Nguyên tắc            | Diễn giải                                                                  |
| --------------------- | -------------------------------------------------------------------------- |
| Phản hồi tức thì      | Mỗi hành động (thêm giỏ hàng, gửi order) có phản hồi rõ ràng               |
| Khôi phục lỗi dễ dàng | Cho phép sửa/hủy trước khi gửi order                                       |
| Giảm tải nhận thức    | Chia nhóm món, tìm kiếm, lọc theo danh mục                                 |
| An toàn & tin cậy     | Xác nhận trước hành động quan trọng (gửi order, thanh toán) tránh nhầm lẫn |

## Ghi chú theo mô hình

_Một số mô hình sẽ có mood/style riêng (VD: nhà hàng cao cấp cần giao diện sang trọng, quán phở cần tốc độ) — chi tiết xem tại Các mô hình hoạt động._
