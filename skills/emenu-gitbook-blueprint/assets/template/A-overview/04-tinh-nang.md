## Problems — How to solve

| Vấn đề khách gặp             | Cách E-Menu giải quyết                            |
| ---------------------------- | ------------------------------------------------- |
| Menu giấy khó cập nhật       | Cập nhật món/giá tức thời trên hệ thống           |
| Nhân viên order sai          | Khách tự chọn món, giảm nhập liệu thủ công        |
| Khách chờ lâu                | Gọi món trực tiếp, không phụ thuộc nhân viên      |
| Khó upsell                   | Gợi ý combo/topping ngay trong flow chọn món      |
| Rủi ro order từ xa/trùng đơn | Xác thực bàn, xác nhận trước khi gửi, chống trùng |
