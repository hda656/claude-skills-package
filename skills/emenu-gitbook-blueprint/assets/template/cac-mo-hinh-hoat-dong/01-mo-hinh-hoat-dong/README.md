# 3. Các mô hình hoạt động

Mỗi mô hình kinh doanh có một "bản vẽ công năng" vận hành riêng. Dùng bảng dưới đây để tư vấn nhanh cùng khách hàng: hỏi khách đang ưu tiên điều gì nhất, từ đó chọn đúng mô hình.
