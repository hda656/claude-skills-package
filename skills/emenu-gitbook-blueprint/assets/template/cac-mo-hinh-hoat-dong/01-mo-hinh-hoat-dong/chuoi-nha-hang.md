# Chuỗi nhà hàng

## Mục tiêu

Đồng bộ menu / giá / khuyến mãi giữa nhiều chi nhánh, phân quyền quản trị.

## Phù hợp với

* Chuỗi F\&B nhiều chi nhánh
* Thương hiệu nhượng quyền

## Workflow tổng quan

<figure><img src="../../.gitbook/assets/no-image.png" alt=""><figcaption>Dán ảnh vào đây</figcaption></figure>

## Tính năng bắt buộc

* Quản lý menu tập trung
* Phân quyền theo chi nhánh
* Đồng bộ dữ liệu

## Tính năng tùy chọn

* Báo cáo so sánh chi nhánh
* Khuyến mãi theo khu vực

## Cơ chế an toàn

* Phân quyền truy cập
* Kiểm soát chỉnh sửa menu theo vai trò

## Giá trị mang lại

Quản lý tập trung, mở rộng chi nhánh dễ dàng, dữ liệu đồng bộ.
